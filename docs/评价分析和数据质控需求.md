评价分析

评价分析模块共包括这三个页面，每个页面对应的需求和功能点如下：
1.综合评价分析
这块内容参考综合监测页面的监测数据看板弹出框，就是把这块功能复制过来展示即可
2.评价标准查看
参考 docs/水质监管项目.openapi.json 接口定义文档中评价标准配置相关接口定义，封装相应的接口，实现相应的功能，页面样式结构要参考其他管理页面比如监测数据管理，要仔细对照接口传参以及返回的数据结构，把已有的接口定义功能都实现出来
3.评价标准查看
参考 docs/水质监管项目.openapi.json 接口定义文档中评价标准文件管理相关接口定义，封装相应的接口，实现相应的功能，支持查看 导入 和 下载
