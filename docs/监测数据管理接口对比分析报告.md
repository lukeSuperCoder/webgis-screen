# 监测数据管理接口对比分析报告

## 一、OpenAPI 文档中已定义的接口

### 1. 监测样本列表查询
- **接口路径**: `GET /monitor/sample/list`
- **状态**: ✅ 已定义
- **参数**:
  - `monitoringWellCode` (string, 可选) - 监测井编号
  - `startTime` (date-time, 可选) - 开始时间
  - `endTime` (date-time, 可选) - 结束时间
  - `projectId` (string, 可选) - 项目编号
  - `pageNum` (int32, 可选) - 页码
  - `pageSize` (int32, 可选) - 每页大小
- **响应**: `TableDataInfo` 标准分页格式
- **前端实现**: `getSampleList()` ✅ 已实现
- **使用位置**: `src/views/data-manage/monitoring-data.vue`

### 2. 获取监测井水质数据
- **接口路径**: `GET /monitor/sample/data`
- **状态**: ✅ 已定义
- **参数**:
  - `monitoringWellCode` (string, 必填) - 监测井编号
  - `date` (date-time, 可选) - 时间(默认当前时间)
- **响应**: 监测井的水质数据（所有指标）
- **前端实现**: `getSampleData()` ✅ 已实现
- **使用位置**: 未在监测数据管理页面使用

### 3. 获取时间范围内单项指标数据
- **接口路径**: `GET /monitor/sample/data/range`
- **状态**: ✅ 已定义
- **参数**:
  - `monitoringWellCode` (string, 必填) - 监测井编号
  - `startTime` (date-time, 必填) - 开始时间
  - `endTime` (date-time, 必填) - 结束时间

- **响应**: 时间序列数据
- **前端实现**: `getSampleDataRange()` ✅ 已实现
- **使用位置**: 未在监测数据管理页面使用

### 4. 获取所有水质指标
- **接口路径**: `GET /monitor/sample/metrics`
- **状态**: ✅ 已定义
- **参数**: 无
- **响应**: 所有水质指标列表
- **前端实现**: `getSampleMetrics()` ✅ 已实现
- **使用位置**: `src/views/data-manage/monitoring-data.vue` (用于下拉选项)

### 5. 导入监测样本数据
- **接口路径**: `POST /monitor/sample/import`
- **状态**: ✅ 已定义
- **请求体**: `multipart/form-data` (binary)

## 四、需要调整的接口

### 1. 监测样本列表查询接口参数调整
**当前前端实现** (`monitoring-data.vue`):
- 使用 `samplingTime` 数组（日期范围选择器）
- 转换为 `startTime` 和 `endTime` (ISO格式)

**OpenAPI 定义**:
- 直接使用 `startTime` 和 `endTime` (date-time格式)

**状态**: ✅ **已正确实现**，前端已做格式转换

### 2. 导入接口 Content-Type 调整
**当前前端实现**:
```javascript
headers: {
  'Content-Type': 'multipart/form-data'
}
```

**OpenAPI 定义**:
- `application/json` (binary)
- `application/octet-stream` (binary)

**建议**: 
- ⚠️ **需要确认**: OpenAPI 文档中导入接口的 Content-Type 定义可能不正确
- 实际应该是 `multipart/form-data`，前端实现是正确的
- 建议后端更新 OpenAPI 文档，明确使用 `multipart/form-data`

### 3. 删除指标接口参数传递方式
**当前前端实现**:
```javascript
deleteMetric(metricIds) {
  return request({
    url: '/monitor/metric',
    method: 'delete',
    data: metricIds  // 使用 data 传递
  })
}
```

**OpenAPI 定义**:
- 使用路径参数: `DELETE /monitor/metric/{ids}`

**建议**: 
- ⚠️ **需要调整**: 前端实现与 OpenAPI 定义不一致
- 应该改为路径参数: `/monitor/metric/${ids}`
