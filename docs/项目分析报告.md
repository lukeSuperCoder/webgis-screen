## 项目概述

### 基本信息

**项目名称**: WebGIS 呼市水质监测系统
**项目类型**: 水质监测地理信息系统
**开发框架**: Vue.js 2.6.14
**当前状态**: 前端功能基本完成，部分模块使用静态数据，待与后端联调

### 项目背景

本系统是一个基于WebGIS技术的水质监测平台，面向呼伦贝尔地区的水质监测管理需求，提供水质数据可视化、空间分析、监测井管理和实时监控功能。系统采用前后端分离架构，前端基于Vue.js和OpenLayers开发，实现了完整的地图可视化和数据管理功能。

### 项目特色

1. **自研OpenLayers封装库**: 完整的地图功能封装，支持21种标记形状
2. **动态图例系统**: 根据不同水质参数自动切换图例展示
3. **多底图支持**: 天地图矢量、影像、地形三种底图无缝切换
4. **空间数据处理**: 支持WKT格式空间数据解析和GeoJSON格式展示
5. **响应式设计**: 支持多种屏幕尺寸，提供良好的用户体验

## 功能模块详解

### 1. 地图可视化模块

#### 核心组件: ScreenMap.vue

**文件位置**: `src/components/ScreenMap.vue:1`
**代码行数**: 1399行
**功能职责**: 系统的核心地图展示组件

**主要功能**:

1. **地图初始化**
   - 基于OpenLayers 10.5.0
   - 默认中心点: [112.1, 43.6]
   - 默认缩放级别: 9

2. **多底图支持**
   - 天地图矢量底图(带注记)
   - 天地图影像底图(带注记)
   - 天地图地形底图(带注记)

3. **图层管理**
   - 标记图层(Marker Layer): 水质点位、监测井
   - 几何图层(Geom Layer): 行政区划、项目边界
   - 热力图图层(HeatMap Layer): 水质热力分布
   - 聚类图层(Cluster Layer): 密集点位聚合
   - 流线图图层(FlowLines Layer): 水流方向

4. **标记形状支持** (21种)
   - 基础形状: 圆形、方形、三角形、菱形、五角星
   - 特殊形状: 圆形带加号(shapeType: 21)
   - 自定义颜色、大小、边框

5. **弹窗系统**
   - 综合水质弹窗: 显示水质类别、指标数据
   - 监测井信息弹窗: 井点编号、类型、成井时间、井深等
   - 单项参数弹窗: pH值、总磷值等

6. **图例系统**
   - 动态图例: 根据当前显示参数自动切换
   - 水质类别图例: I-V类、劣V类(6级)
   - pH值图例: I类、劣V类(2级)
   - 总磷图例: I-劣V类(6级)

```javascript
    this.ws.onmessage = (event) => {
      const data = JSON.parse(event.data)
      this.handleMessage(data)
    }
  }

  handleMessage(data) {
    // 处理实时数据
    if (data.type === 'monitoring') {
      this.updateMonitoringData(data.payload)
    }
  }
}
```

### D. 常见问题解答

#### Q1: 地图加载缓慢怎么办?

**A**:
1. 检查天地图密钥是否有效
2. 检查网络连接
3. 考虑使用离线地图瓦片
4. 实现地图图层懒加载

#### Q2: 监测井数据不显示?

**A**:
1. 检查API接口是否正常
2. 检查数据格式是否正确(特别是WKT格式)
3. 检查坐标系统是否统一(建议使用EPSG:4326)
4. 查看浏览器控制台错误信息

#### Q3: 如何添加新的水质指标?

**A**:
1. 后端数据库添加新指标字段
2. 更新监测数据API返回格式
3. 前端组件添加新指标展示
4. 更新指标配置管理

#### Q4: 如何自定义地图标记样式?

**A**:
```javascript
// 在ScreenMap.vue中
const marker = {
  coordinates: [lon, lat],
  style: {
    shapeType: 0,      // 0-20种形状
    radius: 10,        // 半径
    fillColor: '#ff0000',  // 填充颜色
    strokeColor: '#fff',   // 边框颜色
    strokeWidth: 2     // 边框宽度
  }
}
```

支持的shapeType:
- 0: 圆形
- 1: 方形
- 2: 三角形
- 3: 菱形
- 4: 五角星
- ...
- 21: 圆形带加号
