## ⚠️ 重要注意事项

### 1. API接口确认
在开始开发前，**必须**与后端确认以下问题（参考《00-API对比分析报告》第6节）:
- [ ] 监测井删除接口是否已实现
- [ ] 监测数据新增/编辑接口是否提供
- [ ] 项目删除接口是否已实现
- [ ] 指标编码查询接口的实际路径
- [ ] 监测井更新接口的参数传递方式

### 2. 数据格式
注意以下数据格式（参考《00-API对比分析报告》第5节）:
- **WKT格式**: `"POINT(112.016666 43.54075)"`
- **日期时间格式**: ISO 8601 `"2025-10-20T17:48:00"`
- **省市区代码**: 分别存储为 provinceCode, cityCode, countyCode

### 3. 性能考虑
对于大数据量场景（参考《01-地图监测页面联调方案》第6节）:
- 使用批量查询策略
- 实施分批加载
- 考虑请求缓存
- 使用地图聚类
